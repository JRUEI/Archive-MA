# 字稿翻譯與修飾原則

日文影片 → 繁體中文（台灣用語）逐字稿。以 `content/videos/BTraK6PHUp0.md` 為基準整理。

## 1. 翻意思，不翻字面
- 以「一整句話」為單位理解後再切行，不要逐行硬翻。字幕行是時間切點，不是語意邊界。
- 日文常省略主語。每行都要確認**誰在說、說的是誰**（說話者本人？馬？對方？），避免主語錯置。
  例：「私って基本は夜型なので」是說話者自己，不是馬（36:39）。
- 語氣詞、口頭禪（えっと、あのー）可省，但會影響語氣的（「ね」「でしょ」）要用中文語助詞帶出。
- 日文的固定說法要換成中文自然說法：夜型 → 夜貓子、くれくれオーラ → 「給我給我」的氣場。
- 不要用過重的對應詞：クール 是「酷」，不是「冷酷」。

## 2. 字幕行的寫法
- 一行一個意思單位，口語、短句，結尾標點用 `，` `。` `？`；被打斷的話用 `……`。
- 同一句被拆成多行時，前一行以 `，` 收尾、不要提前句號。
- 笑聲、音效用全形括號註記：（笑）、（尖叫聲）。
- 數字與中文之間不加空格；半形數字、全形中文標點。
- 旁白（影片敘述）與對話分開：旁白用書面、完整句；對話用口語。

## 3. 專有名詞與用詞統一
- 人名、賽馬娘名、馬名：維持片假名原文（シュヴァルグラン、ブーちゃん），不自行音譯。
- 統一用詞：廄務員、廄舍、馬房、放牧地、牧場。
- 只有日文圈才有的詞，第一次出現時在句內順帶解釋（例：「ヘイレージ」是一種飼料，……）。
- 英文外來語（yearling、ヘイ=hay）：說話者在「解釋這個詞」時保留原詞，之後用中文通稱（一歲馬、乾草）。

## 4. 把 ASR 當線索，不當答案
- `*.ja-orig.json3`（YouTube 日文自動字幕）常聽錯、漏句，只用來對時間與確認大意。
- 與日文有出入時，以影片實際聽到的為準；沒把握的行在 commit 訊息或回報中標出，不要硬改。
- 補漏句時用 `[起-訖]` 加新行，起訖不得與前後行重疊。

## 5. 修完要做的事
1. `npm run validate:content`
2. 在本機播放該時間點，確認字幕與聲音對得上。
3. 不確定的語意（專有名詞、聽不清的詞）列給使用者確認，不自行定案。
