# 曲目

一首歌一節：基本資料、背景、出現在哪支影片的哪裡。哪場演出唱了哪首看 `events/`。

**歌詞**放 `docs/glossary/lyrics/<曲名>.md`（檔名用曲名原文，例 `lyrics/SHAKEROCK.md`）。repo 是公開的，那個資料夾已列入 .gitignore，只留在本機給翻譯時對照；字幕裡照樣不放歌詞（標（演唱）／（朗誦〈曲名〉歌詞））。

每節格式：
- 演唱：
- 作詞／作曲：
- 出處：
- 背景：
- 影片出現：`<ID> 時間` — 怎麼出現（整段演唱／片段 BGM／發言引用歌詞）
- 歌詞檔：lyrics/<曲名>.md（有沒有）
