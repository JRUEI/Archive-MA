# 已審核過的譯法

翻過、使用者看過或改過的說法，下次照用。通用原則在 guidelines §1–3。

## 標註

| 情況 | 寫法 |
|---|---|
| 唱歌（ASR 把歌詞聽成字幕） | （演唱），不翻歌詞 |
| 發言中朗誦歌詞 | （朗誦〈曲名〉歌詞），例：okctzi 08:39（朗誦〈SHAKEROCK〉歌詞） |
| 表演中的短劇台詞 | 不翻（okctzi 55:53–56:20 キャロットマン短劇） |
| 歌名 | 字幕內用「」 |
